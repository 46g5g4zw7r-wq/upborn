# Upborn

Браузерная игра-симулятор жизни: ты рождаешься случайно в одной из 24 стран в 2026 году и пытаешься выбраться из бедности — дома или эмигрировав в Канаду, США, Австралию, Германию или Великобританию.

Статус: в разработке. Перевод на 8 языков (ru, en, zh, es, hi, ar, fr, bn) — в процессе.

Один файл `index.html`, без сборки и внешних скриптов.
