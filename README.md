# Upborn

Браузерная игра-симулятор жизни: ты рождаешься случайно в одной из 24 стран в 2026 году и пытаешься выбраться из бедности — дома или эмигрировав в Канаду, США, Австралию, Германию или Великобританию.

Статус: в разработке. Перевод на 8 языков (ru, en, zh, es, hi, ar, fr, bn) — в процессе.

Один файл `index.html`, без сборки и внешних скриптов.

## Безопасность

- В коде есть только публикуемый ключ Supabase (`sb_publishable_...`). Он рассчитан на браузер.
- Секретный ключ (`sb_secret`) в код, README и чаты не попадает. Если он где-то засветился, его нужно перевыпустить в панели Supabase.
- Защита данных держится на правилах доступа (RLS) в Supabase: прямой запись в таблицы закрыта, работа идёт только через функции `heartbeat`, `report_life` и `online_now`.
- Игра не собирает личные данные. В браузере хранятся только случайный ID игрока (`upborn.pid`), язык и настройка музыки.
